# Ahmad Babu — Student Developer Portfolio

A responsive, dark navy and cyan portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website structure and content
- `style.css` — colors, layout, responsive styles and animations
- `script.js` — mobile navigation and scroll reveal effects

## Run on a phone
1. Keep all three files in the same folder.
2. Open `index.html` in a browser or use an online HTML editor that supports multiple files.
3. For the Google Fonts import to load, the browser needs an internet connection. The website otherwise uses fallback fonts.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `ahmad-portfolio`.
2. Upload all three files to the repository root (not inside a nested folder).
3. Open repository **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. After deployment finishes, open the Pages URL shown by GitHub.
